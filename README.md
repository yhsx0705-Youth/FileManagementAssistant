# 文件管理辅助器

一个简单的 Windows 窗口，用来保存重要文件和文件夹的路径。

Windows x64 安装包安装到当前用户的本地程序目录，不需要管理员权限；可从开始菜单或桌面启动，也可从 Windows「设置 > 应用」卸载。

## 使用

双击 **文件管理辅助器.exe** 或 **启动辅助器.bat**。

1. 点击上方「添加」，展开输入区。
2. 粘贴文件/文件夹路径、Windows `.lnk` 快捷方式路径或 `http/https` 网页地址，也可点击「选择文件」「选择文件夹」。拖入 `.url` 网页快捷方式会读取并保存其中的网址。路径框支持 `Ctrl + V` 和右键「粘贴」，也支持资源管理器复制的带引号路径。
3. 点击「保存」添加入口，输入区会自动收起；点击「取消」则放弃本次输入。添加时只需填写路径，不提供自定义名称输入。
4. 双击列表中的入口即可打开。

「选择文件」「选择文件夹」「保存」「取消」在展开输入区时显示于顶部「添加」按钮右侧，横向排列。

主区域分成「文件夹」「文件」「快捷方式」「网页链接」四块，每块都有小图标。抓住区域标题拖到另一块即可交换位置；拖动时会跟随显示区域名称，并高亮目标区域。布局会自动保存。点击「显示区域 (数量/4)」打开设置，勾选后点「保存」一次应用全部更改；至少保留一个区域。显示两个区域时会各占一半，单个区域会铺满主区域，不留空格。PDF、Word、Excel 等优先使用 Windows 的文件类型图标；没有关联程序时使用备用图标。

网页链接可双击打开，右键复制网址或修改列表显示名称。快捷方式添加时会在辅助器数据目录中保存完整的独立副本，包括启动参数、工作目录和商店应用信息；双击或协同开启使用这份副本。因此，收藏成功后可以删除桌面上的原快捷方式。修改名称只改辅助器中的显示名称，移除入口也不会删除桌面快捷方式或目标程序。已存在的快捷方式会在新版启动时自动保存副本；如果旧快捷方式已经删除且尚无副本，可右键「重新导入快捷方式…」选择一次新的快捷方式，保留原入口 ID 与协同开启预设。

从资源管理器或桌面把文件/文件夹拖到辅助器的任意界面区域，即可添加入口。支持一次拖入多个，重复入口自动跳过。普通文件和文件夹保存原路径；快捷方式额外保存独立副本，桌面原件保留。

文件列表中的条目可以拖出辅助器，放到桌面或其他文件夹后由资源管理器复制一份；只提供复制，不提供移动。文件夹条目不支持拖出，仍可通过右键「复制文件夹 (Ctrl+C)」后粘贴来复制。无论哪种复制方式，原文件、原文件夹和辅助器中保存的原路径都保持不变。

文件夹、文件、快捷方式和网页链接四个列表均支持按住条目并上下拖动调整顺序。拖动时会显示跟随鼠标的名称提示和蓝色插入位置线，松开后落位并自动保存，重启程序也会保留。拖到列表上下边缘可以自动滚动；拖到其他列表或按 `Esc` 会取消排序。只有文件支持拖出窗口复制，其他三类拖出窗口会取消排序。排序只改变入口排列，不移动原目标，也不改变协同开启预设里的启动顺序。手动排过序的列表，新入口会添加在末尾。

列表默认只显示名称和图标。勾选下方「显示路径」可展开完整路径，取消勾选即可隐藏。长路径可以通过列表下方的横向滚动条查看。

右键菜单按目标类型显示操作。文件始终显示原文件名，可选「重命名原文件…」；输入新名称并保存后，会修改磁盘上的原文件名称，同步更新入口路径，文件扩展名会保留。同名目标不会覆盖，保存入口失败时会尝试恢复原文件名。

文件夹只做入口管理。右键「修改显示名称…」只修改列表中的表面名称，原文件夹的名称、路径和内容保持不变；输入区留空保存可以恢复显示原名。文件夹不提供原文件夹重命名或删除操作。

本地文件、文件夹和快捷方式可右键「打开文件所在位置」或「移除入口」。网页链接没有本地所在位置。已取消「修改路径」，不能只改入口记录而让磁盘路径与入口脱节。「打开文件所在位置」会打开目标的上一级文件夹，即使文件已被移走，只要上一级仍存在也能打开。「移除入口」只清除辅助器中的记录，不会改动磁盘上的目标；文件已不存在时也可用它清理失效入口。右键空白处不会操作其他入口。

复制实际文件或文件夹：选中条目后右键「复制文件」或「复制文件夹」，也可按 `Ctrl+C`；再选中目标文件夹并按 `Ctrl+V` 或右键「粘贴」。文件和文件夹也可粘贴自资源管理器，支持一次粘贴多个项目。复制在后台进行，原项目保留；同名项目自动另存为副本，不会覆盖已有内容。完成后自动添加新文件的入口。路径输入框中的 `Ctrl+V` 仍用于粘贴路径。

要删除磁盘上的原文件，请右键选择红色「删除原文件…」。必须经过三次点击确认：第一次查看红色警告和完整路径，点击继续；第二次再次核对并继续；第三次点击「确认删除」后才会执行。不需要输入任何文字。任一步取消或关闭窗口均不会删除。文件会移入回收站，无法回收时停止，不自动改为永久删除。成功后移除对应入口。只想从列表去掉文件时，请选「移除入口」；文件夹不能删除，只能移除入口。

回收站操作使用 Windows 的 [IFileOperation 回收标志](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-ifileoperation-setoperationflags)，不依赖第三方库，需要 Windows 8 或更新版本。

入口仅在列表获得焦点且已选中时显示蓝色。点击列表空白处、输入框或界面空白处会取消选择；添加入口后不会自动选中。

关闭程序后入口会自动保留。文件由 Windows 默认程序打开，文件夹由资源管理器打开。文件移动或外接磁盘断开时，原入口仍保留；可移除失效入口后，从实际新位置重新拖入。辅助器内重命名文件会同步更新入口路径。

## 剪贴板与协同开启

每张剪贴板卡片都支持文字与多张图片混合编辑。在卡片内容框内按 `Ctrl+V` 或右键「粘贴」，图片会插入光标处；可以反复粘贴，或一次复制多个图片文件后粘贴到同一张卡片。文字和图片按编辑顺序自动保存，重启后仍保留；选中图片后按删除键即可移除。卡片「复制」提供图文格式（接收软件需支持 HTML 图文粘贴），右键图片可单独复制该图片。旧版图片卡片自动转为可继续编辑的图文卡片。图片与文字记录一起保存在 `workspace.json`，单张图片最大约 36 MB。

右下角「打开剪贴板」会在主窗口右侧打开独立小窗口，并保留一条简洁的小间距；屏幕右侧空间不足时自动放到主窗口左侧，避免窗口跑出屏幕。点击「＋」创建文本卡片，可修改标题、粘贴或编辑文字，点击「复制」把整张卡片内容放入系统剪贴板。按住卡片左侧的「☰」上下拖动可调整卡片顺序，蓝色插入线会提示落点，松开后自动保存。右侧加宽的高对比度滚动条用于浏览长卡片列表，也可直接使用鼠标滚轮。每张卡片的文本框底部有一条细拖动柄，可上下拖动调整高度；顺序、高度、文字和折叠状态都会自动保存，重启后仍然保留。左侧箭头可折叠或展开，关闭小窗口后可再次打开。这里保存手动输入的常用文本，不自动收集系统剪贴板历史。

点击「快捷方式」标题栏内的「协同开启」（右键也可进入），勾选快捷方式并手动填写序号，点击「确定打开」按序启动。勾选时自动填入下一个序号，仍可手动修改；序号不能重复。启动之间间隔一秒，表示发出打开指令的顺序，不等待前一个程序完全加载。启动期间可点「停止开启」停止后续项目。

点击「预设 > 新建预设…」或「协同开启」，勾选快捷方式、标定序号、填写名称，点击「仅保存」即可提前创建预设，不会启动任何程序。「打开时保存」默认不勾选；需要边启动边保存时再勾选，整个过程不弹出保存询问。已保存的预设出现在标题栏的「预设」入口中，点击名称即可再次开启；「管理预设」支持编辑名称、启动顺序和成员，也可删除预设。

预设独立保存启动副本，不依赖列表中入口是否还存在。移除辅助器里的快捷方式，或删除桌面上的原快捷方式后，预设仍能启动保存的目标；后续重新导入其他目标也不会悄悄改变旧预设。如果某个副本确实不可用，会跳过该项目、继续启动剩余项目，并在状态栏显示跳过原因；全部不可用时也不会弹出报错。旧预设会尽量从收藏与备份补全启动信息，无法恢复的成员可在管理预设中重新选择。

快捷方式读取独立副本对应的 Windows 桌面图标（含快捷方式小箭头）。所有网页链接统一显示蓝色小地球。

## 后台运行与边缘吸附

主界面下方的「关闭悬浮球 / 打开悬浮球」可保存启用状态。关闭后最小化或关闭主面板均不弹出小球，主窗口也不再自动贴边收起；可通过任务栏、托盘或再次启动程序显示主界面，再手动开启悬浮球。剪贴板继续独立显示。

右键悬浮球或托盘图标，选择「悬浮球大小」可调整为 100%、125%、150%、175%、200%。原来的大小为最小档 100%（44 像素），最大档直径为两倍（88 像素）。大小自动保存，放大后仍支持半球显示、悬停展开和贴边吸附。

最小化保留任务栏入口，同时显示悬浮球；点击任务栏入口或悬浮球都能恢复主界面，恢复后悬浮球收起。关闭按钮仍隐藏主界面并转入后台。已打开的剪贴板独立显示，主窗口最小化、关闭或贴边收起时都可继续编辑剪贴板；只有关闭剪贴板自身或选择「退出程序」才会关闭它。

点击窗口右上角最小化或关闭按钮，只要主界面离开屏幕，就会显示一个小圆形悬浮球并继续在后台运行。点击小球可打开主界面；按住小球可拖动，松开后平滑吸附到当前屏幕最近的左、右或上边缘。停靠时只显示半球，鼠标移上去会平滑展开成完整小球，移开约 0.6 秒后收回半球；经过小球不会自动弹出主界面。拖动中显示完整小球，再次按住可立即打断吸附动画。半球裁剪在当前屏幕内，不会露到相邻显示器上。关闭「边缘吸附」后可自由放置，显示完整小球。小球右键菜单可显示主界面、打开剪贴板或退出程序。

任务栏右下角仍保留辅助器托盘图标。点击托盘图标或再次双击启动程序也能恢复已运行的窗口；需要完全结束程序时，选择小球或托盘菜单里的「退出程序」。

悬浮球、系统托盘、窗口、程序和安装包统一使用专属的深蓝灰底、银白折页图标。运行所需图片随程序打包，离线也可显示。

拖动主窗口靠近当前屏幕的左、右或上边缘，松开后也会平滑吸附。鼠标离开约 0.6 秒后，主窗口以短距离滑动和淡出收起为半球，点击小球平滑恢复；不会留下窗口窄条。移回窗口或打开的剪贴板可取消本次收起等待。支持不同显示器的工作区域，最大化窗口不自动收起。「边缘吸附」设置会自动保存。

## 数据

安装版入口记录保存在 `%LOCALAPPDATA%\文件管理辅助器\entries.json`，上一次记录保存在同目录的 `entries.backup.json`。升级安装会保留收藏。卸载会移除程序、快捷方式和应用注册项，默认保留收藏与设置；如需完全清理，可在卸载向导中勾选删除用户数据。原文件、文件夹和网页目标不会被卸载程序操作。

开发版数据保存在项目目录的 `data` 文件夹。安装版不会打包开发者本机的 `data`、测试数据或源码。

文本卡片与协同开启预设保存在同一数据目录的 `workspace.json`，备份为 `workspace.backup.json`。它们与入口记录分开保存，升级保留，卸载时与收藏设置采用同样的保留规则。

独立收藏的快捷方式保存在数据目录的 `shortcuts` 子目录。原始导入路径仍留在入口记录中，用于识别重复添加；界面「显示路径」显示实际使用的独立副本位置。相同内容、相同文件名的副本按内容摘要复用，反复删加不会不断创建重复副本。清理缓存时保留当前入口、预设及两者备份需要的副本，仅清理确认无引用的新格式缓存；旧格式副本保留以支持升级恢复。原程序及其安装目录不包含在这些副本中，卸载原程序后仍需重新安装。

## 开发

Python 3.10 及以上，包含 Tkinter。原生拖拽使用 tkinterdnd2 0.6.4；打包后的 EXE 已包含组件。开发运行：

```powershell
python -m pip install -r requirements.txt --target .vendor
python main.py
python -m unittest discover -s tests -v
```

打包需要 PyInstaller：

```powershell
python -m pip install pyinstaller
.\build.ps1
```

制作 Windows x64 安装包需要 NSIS 3，并确保 `makensis.exe` 在 `PATH` 中。运行 `.\build-installer.ps1` 会先跑全套测试，再生成版本化安装程序、安装说明和 SHA-256 校验文件到 `release\1.3.9`。

生成 GitHub 发布文件：构建成功后运行 `python tools/package_github.py --version 1.3.9 --stage "build/release-stage-1.3.9-具体构建编号/app"`，将 `--stage` 指向本次构建产生的 `app` 目录。输出位于 `github-release/v1.3.9`，包括安装程序、免安装 ZIP、完整 ZIP、源码 ZIP、发布说明和校验文件。安装程序内置卸载程序，安装后自动生成 `Uninstall.exe`；完整包另附 `Uninstall.cmd` 用于打开已安装版本的卸载向导。向 GitHub 仓库提交解压后的源码，将二进制发布文件放在 Releases。打包使用明确的文件清单，排除个人收藏、剪贴板、备份、缓存与测试产生的数据。

专属图标源图保存在 `assets/app-icon-source.png`，运行资源位于 `quick_access/assets`。修改源图后，运行 `python tools/build_icons.py` 可重新生成多尺寸 ICO、窗口 PNG 和悬浮球 PNG。设计说明和生成提示词见 `assets/README.md`。Pillow 同时用于剪贴板图片读取和预览，打包版已包含此依赖。

独立测试数据目录：`python main.py --data-dir "D:\测试数据"`。
