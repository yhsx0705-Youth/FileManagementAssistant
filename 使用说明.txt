文件管理辅助器 使用说明

一、安装与启动
1. 运行下载的 x64 安装程序。
2. 按向导选择安装位置；可保留默认位置。
3. 开始菜单和桌面快捷方式默认勾选，可按需要取消。
4. 安装完成后，从桌面或开始菜单打开程序。

二、添加入口
1. 点击「添加」，粘贴文件或文件夹路径，也可点击选择按钮。
2. 网页链接可直接粘贴 http/https 地址；Windows .lnk 快捷方式可按文件路径添加。
3. 从资源管理器拖入文件、文件夹或 .url 网页快捷方式，也可添加入口。
4. 点击「保存」。双击列表项目即可打开。

三、整理区域
1. 拖动区域标题可调整四个区域的位置。
2. 点击「显示区域」，勾选要显示的区域，再点「保存」应用。
3. 选中的区域会自动填满空位；至少保留一个区域。
4. 文件夹、文件、快捷方式和网页链接都可在各自列表内上下拖动排序，顺序自动保存。

四、常用操作
1. 右键项目可打开所在位置、复制或移除入口；不同类型显示对应操作。
2. 「移除入口」只从辅助器移除记录，不影响原文件或文件夹。
3. 「删除原文件…」会把文件移入 Windows 回收站，并要求三次确认。
4. 文件可拖到辅助器外复制；复制文件夹可选中后按 Ctrl+C，再选目标文件夹按 Ctrl+V。
5. 卸载时会移除程序和快捷方式，默认保留收藏；可在卸载向导中选择同时删除收藏和设置。

五、数据位置
收藏和设置保存在：%LOCALAPPDATA%\文件管理辅助器
卸载程序不会删除原文件、文件夹或网页目标。

六、剪贴板
在卡片内容框内按 Ctrl+V 或右键「粘贴」，可直接插入图片；同一张卡片可以保存多张图片并混排文字。图片插入光标处，选中后可删除，重启后仍保留。右键图片可单独复制，卡片「复制」提供图文格式供支持的程序粘贴。
1. 点击右下角「打开剪贴板」，在右侧小窗口中点击「＋」创建文本卡片。
2. 剪贴板显示在主窗口旁边并保留一条小间距；右侧空间不足时会自动移到左侧。
3. 文字和标题可以直接编辑，内容自动保存；点击「复制」可复制整张卡片。
4. 拖动文本框底部的细横条可上下调整高度，调整结果会自动保存。
5. 按住卡片左侧「☰」上下拖动可调整顺序，蓝色插入线提示落点；松开后自动保存。
6. 右侧加宽的滚动条用于浏览较长的卡片列表，也可以直接使用鼠标滚轮。
7. 点击卡片左侧箭头折叠或展开。关闭小窗口后，再次打开仍会保留内容、顺序和文本框高度。

七、协同开启快捷方式
1. 点击「快捷方式」标题栏里的「协同开启」。
2. 勾选要打开的快捷方式，填写启动序号；按序号从小到大依次启动。
3. 填写名称，点击「仅保存」可提前创建预设，不会打开程序；也可从「预设 > 新建预设」进入。
4. 点击「确定打开」可依次启动。需要同时留存时勾选「打开时保存」；默认不勾选，不弹出保存询问。
5. 两个启动指令间隔一秒，不等待程序完全加载；点「停止开启」可停止后续启动。
6. 已保存的预设可从「管理预设」编辑。预设独立保存启动副本，移除列表入口不会影响预设。
7. 副本不可用的项目会跳过并在状态栏提示，剩余项目继续启动。

八、图标
快捷方式显示 Windows 桌面对应的图标，网页链接统一显示蓝色小地球。
辅助器的小球、托盘、窗口、程序和安装包统一使用专属的深蓝灰底、银白折页图标。

九、快捷方式独立收藏
1. 添加快捷方式时，会自动保存一份完整副本。提示收藏成功后，可以删除桌面上的快捷方式。
2. 删除桌面原快捷方式后，双击打开和协同开启仍可使用。
3. 已经失效的旧入口，可右键「重新导入快捷方式…」重新选择一次，原预设保留。
4. 快捷方式的显示名称和入口在辅助器内管理，不修改桌面原件或目标程序。
5. 相同快捷方式副本会复用，重复添加同一路径会拦截；无引用的新格式缓存会清理，预设和备份需要的副本保留。

十、后台与边缘吸附
主界面下方可以「关闭悬浮球 / 打开悬浮球」。关闭后不会因最小化、关闭或贴边自动弹出，设置重启保留；通过任务栏、托盘或再次运行程序恢复主界面后，可手动开启小球。
右键小球或托盘，选择「悬浮球大小」可在 100% 至 200% 五档之间调整。原来的大小为最小档，最大直径为两倍；自动保存，重启后保留。
最小化时保留任务栏入口，同时显示悬浮球；从任务栏或小球都能恢复主界面。关闭主面板仍转入后台。剪贴板独立显示，不随主面板最小化、关闭或贴边收起而隐藏，可以继续编辑和保存。
1. 点击窗口最小化或关闭按钮，只要主界面离开屏幕，程序就会在后台显示一个贴边半球；点击小球打开主界面。
2. 小球可以拖动，松开后平滑吸附到最近的左、右或上边缘。鼠标移上去展开完整小球，移开约 0.6 秒后收回半球；经过小球不会自动弹出主界面。
3. 右键小球或托盘可选择「退出程序」彻底关闭；托盘图标和再次双击程序也能恢复主界面。
4. 右键菜单中的「边缘吸附」可开启或关闭；关闭后小球完整显示，可以自由放置。
5. 主窗口同样支持左、右、上方吸附。鼠标离开稍作等待后平滑收起，点击半球恢复；最大化时不会自动收起。
